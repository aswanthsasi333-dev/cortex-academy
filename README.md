# Cortex Academy 
Cortex Academy is an AI-powered modern e-learning platform designed to help students learn technical skills, build professional resumes, and explore job opportunities in one place.
  Features
- 🔐 User Authentication (Login/Register)
- 📚 Interactive Courses
- 📈 Course Progress Tracking
- 📄 Resume Builder with PDF Download
- 👤 Profile Management
- 💼 Job Opportunities Section
- 🎨 Modern Premium UI

 🛠️ Tech Stack
- React.js
- TypeScript
- Tailwind CSS
- Framer Motion
- React Router DOM

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose

## 📌 Courses Included

- MERN Stack Development
- AI & Machine Learning
- UI/UX Design
